# Dearby 맞춤 대기열 실험실

Dearby 맞춤 대기열의 추천을 바꿔 보는 실험실입니다. 이 주소에서는 운영 서버의 추천 시뮬레이션 API(서버 #329, `POST /v1/lab/recommendation/simulate`)가 실제 공개 활동 · 실제 임베딩(KURE-v1) · 실제 규칙으로 계산한 점수 내역과 MMR 순서를 보여 줍니다. 서버에 닿지 못하는 곳(로컬 파일, 다른 출처)에서는 서버 규칙을 옮긴 브라우저 근사 계산기(임베딩 대신 낱말 벡터, 예시 활동)와 동작 추적으로 돌고 그 사실을 화면에 표시합니다.
